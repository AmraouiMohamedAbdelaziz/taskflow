# Checkpoint 01 — Foundation

Status: validated locally. Checkpoint 02 has not started.

## Features implemented

- Separate API and web npm workspaces with a committed dependency lockfile.
- Strict TypeScript, ESLint 10, Vitest, RTL and Supertest configuration.
- React/Vite/Tailwind/Lucide foundation preview (not the task application).
- Express app factory, GET /api/health, consistent JSON 404 and Zod environment validation.
- Node watch development mode, frontend API proxy and bounded server shutdown.
- CI workflow, English README, architecture/API plans, MIT license and AI disclosure.

## Commands executed

- `node --version` / `npm --version`: Node 24.19.0 / npm 11.9.0.
- `npm view` checks for Vite and ESLint versions and ESLint peer compatibility.
- `npm install`: generated package-lock.json and installed dependencies.
- `npm install -D eslint@^10.12.0 @eslint/js@^10.0.0`: replaced unsupported ESLint 9.
- `npm run check`: lint, typecheck, tests and builds, passed after the update.
- `npm run dev`: launched both development servers.
- Node fetch/assert smoke script: direct API health, proxied API health and frontend HTML passed.

## Defects resolved and limitations

- `tsx watch` could not create its IPC socket in this environment; changed the
  development command to Node's native `--watch --import tsx` and verified startup.
- A cross-tool network probe could not reach the earlier process; starting and
  probing servers in the same execution context passed all three smoke checks.
- npm emits an environment-provided `http-proxy` configuration warning. It is
  not generated by repository configuration and did not prevent validation.
- GitHub-hosted CI has not been run; its equivalent local command passed.
- No browser visual audit, dark theme, task UI, CRUD or storage yet. They belong
  to later checkpoints. No claim of complete V1 functionality or security audit.
